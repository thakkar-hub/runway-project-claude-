# Sasha reference

| File | Use |
|---|---|
| `sasha.jpg` | **Primary reference**, passed to every shot by `render.py`. A clean three-quarter face crop from the sheet. |
| `sasha-profile.jpg` | Alternate profile angle. Swap it in (`reference_image` in `shots.json`) if profile shots drift. |
| `sasha-sheet.jpg` | Full character sheet (front, back, close-ups). For humans only. Don't feed it to the generator: the labels and "SOCIAL SALSAA" laptop/mug branding leak into shots. |

Character lock from the sheet:
- Long, wavy dark-brown hair with warm caramel highlights, worn loose with a centre part or in a black claw clip.
- Full brows, large brown almond eyes, a softly defined nose and full lips.
- Gold hoop earrings, a fine gold chain and thin gold rings.
- Off-duty look: an oversized black blazer, a white shirt, wide-leg jeans and a red woven tote.
